Tutorial básico de HTML

Aprenda a estruturar páginas usando as principais tags HTML.

O que é HTML?

HTML significa HyperText Markup Language. Ele usa tags para organizar o conteúdo de uma página, como títulos, parágrafos, imagens e links.

Estrutura básica

Todo documento HTML normalmente começa com esta estrutura:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <title>Minha página</title>
  </head>
  <body>
    Conteúdo visível da página
  </body>
</html>

Tags essenciais

TagPara que serveExemplo
<h1> até <h6>Títulos e subtítulos<h1>Título</h1>
<p>Parágrafos<p>Olá!</p>
<strong>Texto com destaque<strong>Importante</strong>
<a>Links<a href="https://exemplo.com">Visitar</a>
<img>Imagens<img src="foto.jpg" alt="Descrição">
<ul> e <li>Listas não ordenadas<ul><li>Item</li></ul>

Exemplo prático

As tags podem ser combinadas para criar uma página completa:

<h1>Meu hobby</h1>
<p>Gosto de aprender HTML.</p>
<h2>Materiais</h2>
<ul>
  <li>Computador</li>
  <li>Navegador</li>
</ul>

Dicas

  • Feche as tags que possuem abertura, como <p> e </p>.
  • Use o atributo alt para descrever imagens.
  • Mantenha o código indentado para facilitar a leitura.
  • Use tags semânticas, como <header>, <main> e <footer>.
Pratique criando pequenos projetos e consulte a documentação quando necessário.
