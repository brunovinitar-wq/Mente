GitHub para iniciantes

Tutorial de GitHub

Aprenda os conceitos básicos do GitHub para versionar projetos, colaborar com outras pessoas e publicar código na internet.

O que é GitHub?

O GitHub é uma plataforma online para hospedar repositórios Git. Ele permite que você armazene projetos, acompanhe alterações, trabalhe em equipe e publique código.

O Git é o sistema de controle de versões, e o GitHub é a plataforma que facilita a colaboração e o compartilhamento desses projetos.

Passo a passo

1. Crie uma conta no GitHub

Abra o site github.com e cadastre-se gratuitamente.

  • Escolha um nome de usuário.
  • Crie uma senha forte.
  • Verifique seu e-mail.

2. Instale o Git

Baixe e instale o Git no seu computador:

  • Windows: Git para Windows
  • Mac: xcode-select --install ou baixar do site oficial.
  • Linux: use o gerenciador de pacotes da sua distribuição.

3. Configure o Git

Abra o terminal e configure seu nome e e-mail:

git config --global user.name "Seu Nome"
git config --global user.email "seuemail@exemplo.com"

4. Crie um repositório

No GitHub, clique em New repository e preencha:

  • Nome do repositório
  • Descrição
  • Escolha entre público ou privado
  • Marque Initialize this repository with a README (opcional)

5. Clone o repositório

Copie a URL do repositório e use:

git clone https://github.com/seu-usuario/seu-repositorio.git

6. Crie arquivos e faça commits

Dentro da pasta do projeto, faça alterações e salve os arquivos:

git status
git add .
git commit -m "Adiciona arquivos iniciais"

git status mostra as alterações; git add prepara os arquivos; git commit salva uma versão.

7. Envie para o GitHub

Depois de confirmar as alterações, envie para o repositório remoto:

git push origin main

Se o branch padrão for master, use git push origin master.

8. Explore branches e pull requests

Branches permitem criar versões paralelas do projeto. Exemplo:

git checkout -b feature-nova-tela
git push origin feature-nova-tela

Depois, no GitHub, você pode abrir um Pull Request para revisar e unir as mudanças ao projeto principal.

Comandos úteis

  • git init — inicia um repositório local.
  • git log — mostra o histórico de commits.
  • git pull — atualiza seu repositório local com as mudanças do remoto.
  • git branch — lista branches.
  • git merge — junta alterações de uma branch em outra.

Dicas importantes

  1. Faça commits pequenos e com mensagens claras.
  2. Antes de começar, sempre veja o estado do projeto com git status.
  3. Use branches para desenvolver funções separadas.
  4. Revise Pull Requests antes de aceitar mudanças.
  5. Faça backups e sincronize o projeto com frequência.
